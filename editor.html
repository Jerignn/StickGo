HOW TO USE

Open a sheet from pictures/ (foe_*.png or hero_*.png), paint, then SAVE back over the same file and reload the game.

B pen E erase G fill I pick L line R rect
←→ previous / next frame
Ctrl+Z / Ctrl+Y undo / redo
Space play / pause
Alt+click picks a colour

Enemy sheets: 8 frames wide, rows = idle (4), walk (8), attack (6), hit (2), death (6). Feet go on the green ground line; the figure faces right.
Hero sheets: one row of frames.

Game sheets in the list need the page served over http: run python -m http.server in the project folder and open localhost:8000/editor.html. Otherwise use OPEN SHEET.
